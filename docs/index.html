🚀 Zero-Streamlit Pure Python Reactive Framework

Build Reactive Web Apps with Pure Simplicity

PyView executes standard Python scripts top-to-bottom on every user interaction. Built from scratch with an async FastAPI + WebSocket engine, container-scoped identity, dynamic data grids, and instant client-side tabs without complex frontend builds.

uv add pyview

Interactive Preview

How PyView Works in Practice

Here is a complete PyView reactive app on the left, paired with an interactive live simulation on the right. Try clicking the buttons and moving the slider!

app.py 
import pyview as pv

pv.title("Live Analytics Hub")

# Interactive slider control
multiplier = pv.slider("Scale Factor", min_value=1, max_value=10, value=2)

# Two-column layout container
col1, col2 = pv.columns([1, 1])

with col1:
    pv.metric("Base Metric", pv.session_state.get("count", 42))

with col2:
    scaled = pv.session_state.get("count", 42) * multiplier
    pv.metric("Scaled Output", scaled, delta=f"x{multiplier}")

if pv.button("Increment Value 🚀"):
    pv.session_state["count"] = pv.session_state.get("count", 42) + 1

if pv.button("Reset"):
    pv.session_state["count"] = 0

Getting Started

Quick Start Guide

Get a fully reactive web application running locally in less than one minute.

1. Installation

PyView requires Python 3.12 or 3.14+ and leverages modern type annotations.

Terminal 
# Using uv (recommended)
uv add pyview

# Or with standard pip
pip install pyview

2. Write Your First App

Create a file named hello.py:

hello.py 
import pyview as pv

pv.title("Welcome to PyView 👋")
pv.write("Build interactive data apps without touching HTML, CSS, or JS.")

user_name = pv.text_input("What is your name?", value="Developer")
language = pv.selectbox("Favorite Language", ["Python", "Rust", "TypeScript", "Go"])

if pv.button("Generate Welcome Greeting"):
    pv.success(f"Hello, {user_name}! We're thrilled you love {language}.")
    pv.balloons()

3. Launch the App via CLI

Use the pyview run command to start the reactive server:

Terminal 
uv run pyview run hello.py --port 8501
💡
Hot Tip Open http://127.0.0.1:8501 in your browser. Any interaction instantly streams element diffs over WebSockets!
Architecture

Mental Model & Core Principles

Understand the reactive lifecycle that makes PyView intuitive and predictable.

1. Top-to-Bottom Rerun

Unlike traditional event-driven frontend frameworks (which require callback graphs, signal wiring, and manual DOM listeners), PyView apps are pure scripts that execute top-to-bottom on every user interaction.

ℹ️
How an Interaction Flows
  1. User types into a text input or clicks a button in the browser.
  2. The browser sends an asynchronous JSON message over WebSocket to FastAPI.
  3. The SessionManager routes the event to the user's isolated Session.
  4. A background worker thread re-runs the user's Python script from top to bottom with the updated widget values.
  5. A lightweight JSON element tree is emitted and diffed onto the browser DOM.

2. Session State Management

Values stored in standard local variables reset when a rerun occurs. To preserve user variables across multiple reruns, use pv.session_state:

state_example.py 
import pyview as pv

# Initialize default state
if "todos" not in pv.session_state:
    pv.session_state.todos = ["Review PR", "Deploy v0.1.0"]

new_item = pv.text_input("New Todo")
if pv.button("Add Task") and new_item:
    pv.session_state.todos.append(new_item)
    pv.rerun()

pv.write(pv.session_state.todos)

3. Container-Scoped Identity

In traditional frameworks, placing two buttons with identical labels in different columns often causes identity collisions. PyView solves this with automatic hierarchical container scoping:

Every widget tracks its container hierarchy (e.g. columns_0.col_1.btn_0). You can safely place duplicate widgets inside nested layouts without passing manual key="..." parameters everywhere.

4. High-Performance Caching

PyView provides two specialized caching decorators to prevent re-computing expensive operations:

caching_example.py 
import pyview as pv

# 1. @pv.cache_data: For serializable computation, dataframes, and API calls
@pv.cache_data(ttl=300)
def fetch_financial_records(ticker: str):
    # Expensive database or remote fetch
    return load_heavy_dataframe(ticker)

# 2. @pv.cache_resource: For non-serializable objects (ML models, DB connection pools)
@pv.cache_resource
def get_db_pool():
    return create_engine("postgresql://...")

5. Flow Control: rerun() & stop()

Control script branching cleanly with pv.rerun() (immediately re-triggers top-to-bottom run) and pv.stop() (terminates script execution cleanly at that line without error).

API Reference

Complete Component Reference

Explore all 80+ components, widgets, containers, and utilities available in PyView.

pv.columns(spec: int | list[int | float]) -> list[ColumnContainer]
Layout

Creates a responsive multi-column layout. Use with Python's with block to place widgets in specific columns.

Parameter Type Default Description
spec int | list required Integer count of equal columns (e.g. 3) or proportional width weights (e.g. [2, 1]).
columns_usage.py 
col1, col2 = pv.columns([3, 1])
with col1:
    pv.header("Primary View")
with col2:
    pv.metric("Score", 98)
pv.tabs(tab_labels: list[str]) -> list[TabContainer]
Layout

Generates instant client-side tabbed switchers. All tab panes are computed server-side, allowing lag-free tab switches without WebSocket round-trips.

tabs_usage.py 
tab_data, tab_charts, tab_settings = pv.tabs(["📊 Data", "📈 Analytics", "⚙️ Settings"])
with tab_data:
    pv.dataframe(my_df)
with tab_settings:
    pv.checkbox("Enable Dark Mode")
pv.data_editor(data, num_rows="fixed" | "dynamic", column_config=None, key=None)
Data Grid

A fully reactive, interactive editable data grid. Supports inline cell editing, checkbox toggles, dropdown select boxes, and adding or deleting rows dynamically.

Parameter Type Default Description
data DataFrame | list[dict] required Tabular data to populate the grid.
num_rows str "fixed" Pass "dynamic" to allow users to add and remove rows directly in the UI.
column_config dict None Formatters like ProgressColumn, CheckboxColumn, NumberColumn.
pv.dataframe(data, use_container_width=True, hide_index=False)
Data Grid

Interactive data table with instant text search, column sorting, pagination controls, and one-click CSV export.

pv.button(label: str, key: str = None, type: str = "primary" | "secondary") -> bool
Inputs

Displays a clickable button. Evaluates strictly to True during the specific rerun triggered by its click, automatically resetting to False on the subsequent rerun.

pv.slider(label: str, min_value=0, max_value=100, value=None, step=1, key=None)
Inputs

Numeric range slider with customizable step sizing, min/max bounds, and instant reactive updates.

pv.metric(label: str, value: Any, delta: str = None, delta_color: str = "normal" | "inverse" | "off")
Status

Executive KPI card for highlighting key metrics with delta indicators (percentage or difference) and custom color modes.

pv.file_uploader(label: str, type: list[str] = None, accept_multiple_files=False, key=None)
Inputs

Drag-and-drop file uploader that provides in-memory access to uploaded files with read(), name, and size properties.

pv.balloons() & pv.toast(message: str, icon: str = "ℹ️")
Celebrations

Engage users with celebratory animations like full-screen floating balloons or snowfall, and temporary non-intrusive toast notifications.

@pv.cache_data(ttl: float = None, max_entries: int = None)
Core

Function decorator for memoizing computations. Has built-in cache clearing via func.clear().
